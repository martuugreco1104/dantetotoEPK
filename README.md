# DANTE TOTO — Electronic Press Kit (EPK)

Official Electronic Press Kit & Portfolio for **Dante Toto** (@dantetoto_), Argentine DJ and electronic music producer based in Barcelona.

Sound Architecture: **Indie Dance • Dark Tech House • Techno**

## Features
- **Hero Section**: 3D deformable liquid mesh canvas physics, responsive typography, audio preview controls.
- **Audio Control Center**: Interactive waveform player with 62-minute live set recorded at Detroit Club BCN (Sesión Étnica).
- **Live Booth Feed**: 9:16 vertical booth recordings with synced audio controls and VU-meters.
- **Tour Dates & Archive**: Glassmorphic event cards featuring official club flyers (Prismatica, Pandhora, Off Week Generator, Placeo Bridge48) and direct links to Resident Advisor.
- **Official Biography**: Sound spectrum profile, residency coordinates, and club narrative philosophy.
- **Press Photos**: 300 DPI high-resolution downloadable assets with interactive camera reticle viewfinders.
- **Press Kit Hub & Technical Rider**: Visual booth specs (3x CDJ-3000, DJM-V10 / Xone:96), hospitality requirements, downloadable dossiers, and one-click clipboard terminal copy.
- **Direct Bookings**: Interactive contact interface with mailto integration and clipboard utilities.
- **Bilingual Engine**: Real-time Spanish / English (ES / EN) dictionary toggle without page reload.

## Tech Stack
- HTML5 / Vanilla JavaScript (ES6+)
- Tailwind CSS
- Web Audio / Canvas API for real-time physics deformation
- KaTeX & FontAwesome icons
